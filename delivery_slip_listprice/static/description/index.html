Delivery Slip – List Price & Totals

Show the selling price of every outbound item on the delivery slip

Extends the standard Odoo 18 Delivery Slip to add a List Price (public selling price) column and a Grand Total — across all three table variants that can appear on a delivery slip.

Covers all three table types

Aggregated moves

Products without serial/lot tracking — handled via Odoo 18's dict-based aggregated line format.

Serial-tracked moves

Products tracked by serial number — rendered as individual records with monetary formatting.

Done moves + Grand Total

Validated transfer quantities with a grand total footer: Σ (list_price × qty_done).

Technical notes

  • Zero Python — four XPath overrides with priority="300".
  • Uses product.list_price — the pricelist-independent public price.
  • Compatible with Odoo 18 Community and Enterprise.
  • Depends only on stock.
